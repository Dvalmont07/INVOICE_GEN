# Visual Identity Skill: Premium Clean Web Designer

This skill defines the visual identity for the website interface, inspired by the PDF's professional branding.

## Color Palette (Web UI)

| Variable | Color | Usage |
|---|---|---|
| `--brand-charcoal` | `#1A1A1A` | Headings, primary text, navigation bar accents. |
| `--brand-slate` | `#4A5568` | Secondary text and labels. |
| `--brand-bg` | `#F8FAFB` | Main application background. |
| `--brand-surface` | `#FFFFFF` | Form cards, navigation bar, and main container. |
| `--brand-border` | `#E2E8F0` | Subtle borders for inputs and sections. |
| `--brand-accent` | `#3182CE` | Professional blue for primary actions (buttons). |
| `--brand-success` | `#27AE60` | Green for success states and primary actions. |

## Typography 

- **Google Font**: `Inter` (Sans-serif).
- **Headings**: `font-weight: 700`, `letter-spacing: -0.025em`.
- **Body**: `font-weight: 400`, `line-height: 1.6`.

## Structural Principles

1. **Card Layout**: Use white cards with a light border and zero/minimal shadow for form sections.
2. **Table Minimalism**: Tables should have no vertical borders, only horizontal dividers in light gray.
3. **Clean Navigation**: Navbar should be thin, white, fixed at the top, with a subtle border-bottom.
4. **Input Polish**: Use broad focus rings and neutral gray backgrounds for form fields.
